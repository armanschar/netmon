# NetMon — Project Instructions

## Objective

Build a local network monitoring application using Python and FastAPI.

## Engineering principles

- Use type hints.
- Prefer simple, maintainable solutions.
- Avoid unnecessary abstractions and dependencies.
- Use asynchronous I/O where appropriate.
- Never block the API event loop.
- Validate external inputs.
- Use proper logging and error handling.

## Development workflow

- Work in small milestones.
- Explain architectural decisions before implementation.
- Write automated tests for significant features.
- Run tests after changes.
- Never claim tests pass without actually running them.
- Document important changes.
- Do not introduce dependencies without explaining why.

## Learning requirements

- Explain unfamiliar concepts.
- Identify edge cases.
- Explain important design decisions.
- Do not sacrifice code quality for speed.

## Restrictions

- Monitor only authorized local network devices.
- No arbitrary public IP scanning.
- No paid APIs or cloud services.
- No frontend until explicitly requested.
- No unnecessary dependencies.
